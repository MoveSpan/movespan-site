# Protocol Library

Protocols are condition-specific guides that tell AI which exercises, practices and lessons to recommend.

A Protocol is a **constructor**, not a copy.
It contains references (IDs) to entities — not copies of content.

## Canonical Source Principle

| Entity | Canonical Source |
|--------|-----------------|
| Practice | Practice Bible |
| Exercise | Exercise Passport |
| Lesson | Lesson Library |
| Program | Learning Path |
| Condition Protocol | Protocol Library |
| Science | Research Library |

If an exercise changes → update only its Passport.
Everything else references it, never copies it.
