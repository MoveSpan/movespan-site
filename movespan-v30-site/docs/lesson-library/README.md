# Lesson Library

Answers: **How do we teach each practice?**

A lesson ≠ an exercise. One lesson may contain multiple exercises, explanations and media.

## Structure

```
lesson-library/
├── JR/    Joint Recovery lessons
├── BR/    Body Release lessons
└── ...
```

## Lesson Format

Each lesson contains:
- Learning objectives
- Prerequisites
- Content (exercises + explanations + media)
- Assessment / reflection
