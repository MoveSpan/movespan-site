# MoveSpan Resolution 001

**Status:** Approved  
**Date:** July 2026  

---

## Mission

MoveSpan is an intelligent human companion system that helps people move, recover, learn, build healthy habits and support inner development throughout life.

MoveSpan is not an exercise app. It is an ecosystem uniting knowledge, practices, support and personalization.

---

## Core Principle

**Meaning first. Structure second. Code third.**

```
Idea
  ↓
MoveSpan Bible
  ↓
Schema
  ↓
Passport
  ↓
Approval by Methodologist
  ↓
Implementation by CTO
  ↓
Publication
```

**If it's not in the Bible, it doesn't exist in the system.**

---

## Quality Rule

No element enters the application automatically.

Every object goes through:
1. Creation
2. Description (schema + passport)
3. Methodology check
4. Approval by Dmitriy
5. Implementation by Claude
6. Used by AI

---

## Long-term Goal

Build a system that becomes a personal companion in health, movement, recovery and development — not just another feature list.

Every decision must answer: **"How does this help a person live better?"**
