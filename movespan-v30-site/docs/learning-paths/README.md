# Learning Paths

A Learning Path assembles Practices, Exercises and Lessons into a structured course.

Learning Path ≠ Exercise Library
Learning Path ≠ Lesson Library

It is the layer that connects everything into a ready program.

## Structure

```
learning-paths/
├── restore-week-1.md
├── reset-week-1.md
├── expand-week-1.md
└── ...
```

## Format

Each Learning Path contains:
- Mode (Restore / Reset / Expand)
- Week number
- Session list with Exercise Assignments
- Progression logic
