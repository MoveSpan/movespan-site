# Exercise Library

Answers: **What exercises belong to each practice?**

Each exercise has its own passport with full metadata.

## Structure

```
exercise-library/
├── JR/    Joint Recovery exercises
├── BR/    Body Release exercises
├── NG/    Neuro Gym exercises
├── TC/    Tai Chi & Flow exercises
├── WT/    Walking Therapy exercises
├── BW/    Breathwork & Meditation exercises
├── SY/    Strong Body Yoga exercises
├── AQ/    AquaBreath exercises
└── VS/    Voice & Sound exercises
```

## Exercise Passport Template

Each exercise file contains:
- Code, name (EN/RU), practice, zone
- Instructions, Entry/Focus/Exit phases
- Common errors, modifications
- Assets (video, audio, image)
- AI metadata (JSON)
